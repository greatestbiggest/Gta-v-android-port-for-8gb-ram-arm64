#Glue5-Gta-v-android-port-for-6gb-ram-arm64
Android port of Gta v for Android running 6gb ram arm64 mediatek mali-gpu working 
I combined the GTAv port with glue then made numerous patches to run the game on a 6gb mediatek 6100+ processer. on low settings very playable sandbox mode just not hd. standard definition.
working on a 720p version. but video memory and processer strength lacking.
